## 1. 개요 (Overview)
본 과제는 적외선 PSD 센서의 아날로그 출력을 ADC로 읽어 거리로 환산하고, 그 결과를 UART로 출력하는 것을 목표로 함. 센서의 비선형 출력 특성을 다루는 방법과, 측정 원리에서 비롯되는 구조적 한계에 대한 예외처리를 함께 다룸.

### 핵심 목표
* ADC 채널 선택 및 PSD 출력 전압 측정
* 비선형 출력 곡선을 거리 단위로 환산
* Timer 인터럽트를 이용한 일정한 측정 주기 확보
* 측정 범위를 벗어난 값에 대한 예외처리

## 3. 하드웨어 구성 및 핀 맵 (Hardware Structure)

### Pin Configuration

```text
[ATmega128]                 [Target Component]
 PF1 (ADC1)          <-----   PSD Vo (출력)
 PD3 (TXD1)          ----->   USB-Serial 어댑터 RX
 GND                 <---->   PSD GND, 어댑터 GND

[PSD 3핀 커넥터]
 1 : Vo              ----->   PF1
 2 : GND             <---->   보드 GND
 3 : Vcc             <-----   5V
```

### PSD 회로 구성
상세 회로도와 4일차 자료에는 PSD 관련 회로가 포함되어 있지 않음. 과제 안내의 PORTF 할당표에만 PF1이 PSD로 지정되어 있어 직접 배선함.

PSD는 내부에 증폭 회로가 포함되어 있어 전원 2선과 아날로그 출력 1선만 연결하면 됨. 분압 저항 등 외부 회로가 필요하지 않음.

### 핀 할당 변경
기존 핀맵은 PF1부터 PF7까지를 IR 센서 수광부 7개에 할당하고 있었음. 4일차 과제 안내에서 PF1을 PSD로 변경하고 IR 센서를 6개로 축소하도록 지시하고 있어 이에 따름.

```text
변경 전 : PF0 가변저항, PF1 ~ PF7 IR 센서 7개
변경 후 : PF0 가변저항, PF1 PSD, PF2 ~ PF7 IR 센서 6개
```

### 전원 관련 주의사항
PSD는 적외선 LED를 펄스로 점멸시키며 측정하므로 순간 전류 변동이 큼. 데이터시트는 Vcc와 GND 사이에 10uF 이상의 커패시터를 센서 근처에 배치할 것을 요구함. 평균 소비 전류는 약 30mA임.

## 5. 핵심 코드 및 레지스터 설정 (Key Implementation)

### 측정 주기 생성 (hw3.c)
```c
ISR(TIMER0_COMP_vect)
{
    if (++tickCount >= TICKS_PER_PERIOD)
    {
        tickCount = 0;
        measureFlag = 1;
    }
}
```

```text
분주 256  ->  1틱 16us
OCR0 = 124  ->  2ms (오차 0)
2ms x 50 = 100ms 측정 주기
```

인터럽트에서는 깃발만 설정하고 실제 측정과 출력은 메인 루프에서 수행함. ADC 변환과 UART 전송은 시간이 소요되므로 인터럽트 내부에서 처리하면 다른 인터럽트의 처리가 지연됨.

측정 주기를 100ms로 설정한 근거는 센서의 출력 갱신 주기임. Sharp PSD의 출력은 38.3ms ± 9.6ms 주기로 갱신되므로 그보다 빠르게 읽어도 동일한 값이 반복됨. 100ms는 갱신 주기 대비 충분한 여유를 가짐.

### 거리 환산 방식
PSD의 출력 전압은 거리에 반비례하는 곡선이므로 비례식으로는 환산할 수 없음. 거듭제곱 근사식을 사용하는 방법도 있으나 `pow()` 연산이 필요하여 AVR에서는 처리 시간과 코드 크기 측면에서 불리함.

데이터시트의 출력 곡선에서 9개 점을 추출하여 테이블로 구성하고, 점 사이는 직선으로 근사하는 선형보간 방식을 사용함.

| 거리 | 출력 전압 | ADC (10bit, 5V) |
| :--- | :--- | :--- |
| 10 cm | 2.30 V | 471 |
| 15 cm | 1.65 V | 338 |
| 20 cm | 1.30 V | 266 |
| 30 cm | 0.95 V | 194 |
| 40 cm | 0.72 V | 147 |
| 50 cm | 0.59 V | 121 |
| 60 cm | 0.50 V | 102 |
| 70 cm | 0.44 V | 90 |
| 80 cm | 0.40 V | 82 |

```c
*mm = psdTable[i].mm
    + (uint16_t)(((uint32_t)(psdTable[i].adc - adc) * mmSpan) / adcSpan);
```
거리를 mm 단위 정수로 계산하여 부동소수점 연산 없이 소수점 한 자리까지 표현함. 표의 값만 교체하면 다른 모델의 센서에도 대응 가능함.

### 예외처리

PSD의 가장 중요한 특성은 **최소 측정 거리보다 가까운 구간에서 출력이 다시 낮아진다**는 점임. 삼각측량 방식이므로 물체가 너무 가까우면 반사점이 내부 센서 배열의 유효 범위를 벗어나 출력이 감소함.

```text
출력전압
2.3V |      /\
     |     /  \___
     |    /       ----____
0.4V |___/               ----
     +----+----+--------------
         0   10cm       80cm
              ^
        여기가 정점. 그보다 가까우면 다시 내려감
```

이로 인해 5cm와 50cm가 유사한 출력값을 가지며, 단일 측정값만으로는 두 상황을 구분할 수 없음. 따라서 정점을 초과하는 값은 거리로 환산하지 않고 경고로 처리함.

| 조건 | 판정 | 출력 |
| :--- | :--- | :--- |
| ADC > 471 | 10cm 미만. 값이 모호한 구간 | `WARN: TOO CLOSE (<10 cm)` |
| ADC < 82 | 80cm 초과 또는 미검출 | `WARN: OUT OF RANGE (>80 cm)` |
| 82 ≤ ADC ≤ 471 | 정상 측정 | `DIST: nn.n cm` |

이 외에 선형보간 과정에서 구간 폭이 0인 경우에 대한 나눗셈 방어 코드를 배치함.

## 6. 동작 설명 및 결과 (Results)

### 동작 시나리오
1. 전원 인가 시 ADC와 UART1을 초기화하고 Timer0을 시작함
2. 100ms 주기로 PF1의 전압을 측정함
3. 측정값을 테이블 기반 선형보간으로 거리로 환산함
4. 범위를 벗어난 경우 경고 메시지를 출력함
5. UART로 결과를 전송함

```text
PSD distance meter
period 100 ms, range 10-80 cm
ADC: 265  DIST: 20.1 cm
ADC: 194  DIST: 30.0 cm
ADC: 613  WARN: TOO CLOSE (<10 cm)
ADC:  40  WARN: OUT OF RANGE (>80 cm)
```

### 검증 과정에서 확인한 사항

**전원 극성 오결선**
초기 연결 시 ADC 값이 1023으로 고정됨. 부동 상태라면 값이 흔들려야 하나 고정되어 있어 입력이 5V에 연결된 상태로 판단함. 확인 결과 커넥터의 Vcc와 GND가 반대로 연결되어 있었음. 배선 수정 후 정상 동작을 확인함. 선 색상 배열이 일반적인 순서와 달랐던 것이 원인이며, 이후로는 센서 본체의 인쇄 표기를 기준으로 확인함.

**전류 부족에 의한 측정값 표류**
정지 상태에서도 거리값이 한 방향으로 계속 증가하는 현상이 발생함. 원인은 전원 용량 부족으로 판단함. AD-USBISP의 USB 전원은 권장 한계가 100mA인데, PSD가 30mA를 소비하는 상태에서 LED 막대 표시가 최대 72mA를 추가로 소비함. 또한 거리에 따라 점등 개수가 변하면서 소비 전류가 함께 변동하여 전원 레일이 흔들리고, 이것이 다시 ADC 값에 영향을 주는 되먹임 구조가 형성됨. LED 표시를 비활성화하여 개선함.

**근거리 측정값**
센서에 손을 밀착시켰을 때 약 50cm로 표시되는 현상을 확인함. 이는 5절에 기술한 PSD의 구조적 특성에 의한 것으로 오동작이 아님. 손을 서서히 멀리하면 거리값이 증가하며 정상적으로 추종함을 확인함.
