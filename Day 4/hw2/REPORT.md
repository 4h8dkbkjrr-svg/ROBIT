## 1. 개요 (Overview)
본 과제는 Timer0의 비교일치 인터럽트를 시간 기준으로 삼아 달력과 시계를 구현하는 것을 목표로 함. 가변저항과 스위치로 날짜 및 시각을 설정하고, 설정 완료 후 시간이 흐르도록 함. 자리올림과 윤년 판정 등 날짜 연산의 예외처리를 함께 다룸.

### 핵심 목표
* Timer0 CTC 모드를 이용한 오차 없는 시간 기준 생성
* 가변저항과 스위치를 이용한 항목별 순차 설정
* 1/100초 단위까지의 시각 표시
* 윤년, 월별 일수, 자리올림 등 날짜 예외처리

## 3. 하드웨어 구성 및 핀 맵 (Hardware Structure)

### Pin Configuration

```text
[ATmega128]                 [Target Component]
 PF0 (ADC0)          <-----   가변저항
 PC0                 <-----   SW1 (항목 확정 후 다음으로)
 PC1                 <-----   SW2 (시간 시작, 정지)
 PD0 (SCL)           <---->   I2C Text LCD 16x2
 PD1 (SDA)           <---->   I2C Text LCD 16x2
```

### 주요 회로 특징
* **스위치:** 외부 10kohm 풀업 + 104(0.1uF) 커패시터 구조의 Active Low 회로
* **가변저항:** ADC0 입력. 내부 풀업을 비활성화해야 정상 측정됨
* **LCD:** PCF8574 백팩을 통한 I2C 접속. 2일차 과제에서 작성한 드라이버를 그대로 사용함

## 5. 핵심 코드 및 레지스터 설정 (Key Implementation)

### Timer0 CTC 설정 (hw2.c)
```c
void INIT_timer0(void)
{
    TCCR0 = (1 << WGM01) | (1 << CS02) | (1 << CS01);   // CTC, 분주 256
    OCR0 = 124;                                          // 125 * 16us = 2ms
    TCNT0 = 0;
    TIMSK |= (1 << OCIE0);
}
```

| 레지스터 | 설정 | 의미 |
| :--- | :--- | :--- |
| TCCR0 | WGM01 = 1, WGM00 = 0 | CTC 모드. OCR0까지 세고 0으로 복귀 |
| TCCR0 | CS02, CS01 = 1 | 분주비 256 |
| OCR0 | 124 | 비교일치 값 |
| TIMSK | OCIE0 = 1 | 비교일치 인터럽트 허용 |

### 주기 계산과 분주비 선택 근거
Timer0은 8비트이므로 최대 255까지만 셀 수 있음. 16MHz를 그대로 세면 즉시 넘치므로 분주가 필요함.

```text
분주 256  ->  16MHz / 256 = 62500Hz  ->  1틱 = 16us
OCR0 = 124  ->  (124 + 1) x 16us = 2000us = 2ms
2ms x 5 = 10ms = 1/100초
```

분주비 선택 시 목표 주기가 정수로 떨어지는지를 기준으로 삼음. 분주 1024를 사용하면 1틱이 64us가 되어 10ms를 만들기 위해 156.25틱이 필요함. 정수로 떨어지지 않으므로 매 주기마다 오차가 누적되어 시계가 점점 틀어짐. 분주 256과 OCR0 = 124 조합은 나누어떨어지므로 이론상 오차가 0임.

| 분주비 | 1틱 | 10ms에 필요한 틱 | 채택 여부 |
| :--- | :--- | :--- | :--- |
| 1024 | 64us | 156.25 | 소수점 발생으로 제외 |
| **256** | **16us** | **625 (2ms 단위로 5회)** | **채택** |

### 인터럽트 처리
```c
ISR(TIMER0_COMP_vect)
{
    if (!running)
        return;

    if (++tickCount < TICKS_PER_CS)
        return;

    tickCount = 0;

    if (++tCs < 100)
        return;

    tCs = 0;

    if (++tSec < 60)
        return;
    ...
}
```
인터럽트 내부에서는 자리올림만 수행함. 넘치지 않는 경우 즉시 반환하도록 작성하여, 1/100초 갱신 시 대부분의 호출이 첫 두 줄만 실행하고 종료됨. 초 단위 연산은 100회에 1회, 분 단위는 6000회에 1회만 수행되므로 인터럽트 처리 시간이 짧게 유지됨.

### 표시값의 원자적 복사
```c
cli();
cs = tCs; sec = tSec; mi = tMin; hh = tHour;
dd = tDay; mm = tMon; yy = tYear;
sei();
```
시, 분, 초가 각각 별개의 변수이므로 읽는 도중 인터럽트가 발생하면 서로 다른 시점의 값이 섞임. 예를 들어 10:59:59를 읽는 중 초만 0으로 갱신되면 10:59:00이라는 존재하지 않는 시각이 표시됨. 복사 구간에서만 인터럽트를 차단하여 방지함.

### 예외처리

| 항목 | 처리 내용 |
| :--- | :--- |
| 월별 일수 | 31일, 30일, 2월을 구분한 테이블로 판정 |
| 윤년 | 4년 주기, 100년 예외, 400년 재예외 규칙 전체 구현 |
| 설정값 범위 | 월 1~12, 시 0~23, 분과 초 0~59로 제한 |
| 일 설정 범위 | 설정 중인 연월의 마지막 날까지만 선택 가능 |
| 월 변경 후 일 초과 | 1월 31일 설정 후 2월로 변경 시 28일로 자동 조정 |
| 연도 순환 | 두 자리 표기이므로 99년 다음은 00년 |

```c
uint8_t GET_daysInMonth(uint8_t y, uint8_t m)
{
    const uint8_t table[12] = { 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };

    if (m < 1 || m > 12)
        return 31;                          // 범위 밖이면 안전하게

    if (m == 2 && isLEAP_year(y))
        return 29;

    return table[m - 1];
}
```

### LCD 갱신 최소화
I2C는 전송 속도가 느려 16칸 두 줄을 매 루프마다 갱신하면 시계 표시가 끊김. 날짜가 표시되는 1행은 내용이 변경된 경우에만 다시 쓰고, 시각이 표시되는 2행만 매 루프 갱신함. 문자열 비교와 복사는 표준 라이브러리 대신 직접 구현한 함수를 사용함.

## 6. 동작 설명 및 결과 (Results)

### 동작 시나리오
1. 전원 인가 시 스위치와 ADC를 초기화하고 Timer0을 시작함
2. 가변저항을 돌려 연도를 설정하고 SW1로 확정함
3. 같은 방식으로 월, 일, 시, 분, 초를 차례로 설정함
4. 모든 항목 확정 후 LCD에 "SW2 TO START"가 표시됨
5. SW2 입력 시 시간이 흐르기 시작함
6. 동작 중 SW2를 다시 누르면 정지하고, SW1을 누르면 설정 모드로 복귀함

설정 중 화면
```text
+----------------+
|SET MONTH  07   |
|10:50:48.00     |
+----------------+
```

동작 중 화면
```text
+----------------+
|190722   LDY    |
|10:50:48.34     |
+----------------+
```

과제 명세의 예시 "190722 10:50:48.34"는 18글자이므로 16칸 한 줄에 들어가지 않음. 1행에 날짜, 2행에 시각을 배치함.

### 검증 과정에서 확인한 사항

경계 조건은 시각을 23:59:59로 설정한 뒤 자정을 넘기는 방식으로 확인함.

| 시작 시각 | 2초 후 | 확인 항목 |
| :--- | :--- | :--- |
| 2024-02-28 23:59:59 | 24-02-29 00:00:01 | 윤년의 2월 29일 존재 |
| 2025-02-28 23:59:59 | 25-03-01 00:00:01 | 평년의 2월 29일 건너뜀 |
| 2025-04-30 23:59:59 | 25-05-01 00:00:01 | 30일까지인 월의 처리 |
| 2025-12-31 23:59:59 | 26-01-01 00:00:01 | 연도 증가 |
| 2099-12-31 23:59:59 | 00-01-01 00:00:01 | 두 자리 연도 순환 |

시간 정확도는 시작 시각을 기준으로 2초 경과 시점의 값을 대조하여 확인함. 실제 경과 2.000초에 대해 시계도 정확히 2초를 셈.
