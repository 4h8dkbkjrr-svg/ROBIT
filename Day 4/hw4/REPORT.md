## 5. 핵심 코드 및 레지스터 설정 (Key Implementation)

### 이동 평균 필터 (hw4.c)
```c
uint16_t FILTER_movingAverage(uint16_t x)
{
    maSum -= maBuf[maIdx];                  // 가장 오래된 값을 빼고
    maBuf[maIdx] = x;                       // 새 값으로 덮은 뒤
    maSum += x;

    maIdx = (uint8_t)((maIdx + 1) % MA_SIZE);

    if (maCount < MA_SIZE)
        maCount++;

    return (uint16_t)(maSum / maCount);
}
```

최근 N개 표본의 산술 평균을 취하는 방식임. 매번 전체를 더하지 않고 누적합에서 가장 오래된 값을 빼고 새 값을 더하는 방식으로 처리하여 연산량을 일정하게 유지함.

버퍼가 채워지기 전에는 실제로 입력된 개수로만 나눔. 배열 크기로 고정 제산하면 초기 구간에 0이 섞여 값이 실제보다 낮게 나옴.

### 이동 평균의 특성

| 항목 | 내용 |
| :--- | :--- |
| 잡음 감소 | 무작위 잡음은 표본 수의 제곱근에 반비례하여 감소함 |
| 반응 지연 | 값이 변할 때 N개 표본이 모두 교체될 때까지 이전 값에 끌림 |
| 스파이크 | 순간적으로 크게 튄 값 하나가 N회 동안 평균에 포함됨 |
| 메모리 | 표본 N개를 저장할 배열이 필요함 |

구현이 단순하고 동작이 예측 가능하다는 점이 장점임. 반면 스파이크성 잡음에는 상대적으로 취약하며, 표본 수를 늘릴수록 잡음은 줄지만 반응이 느려지는 상충 관계가 있음. 본 과제에서는 표본 수 8을 사용함.

### 샘플링 주기와 출력 주기의 분리

```text
센서 읽기 : 40ms
화면 출력 : 200ms
```

두 주기를 분리한 이유는 필터의 동작 조건 때문임. 필터는 충분한 수의 표본이 있어야 효과가 나타나므로 읽기는 자주 수행해야 함. 반면 사람이 읽는 화면은 그만큼 자주 갱신할 필요가 없음.

읽기 주기 40ms는 센서의 출력 갱신 주기(38.3ms ± 9.6ms)에 맞춘 값임. 그보다 자주 읽으면 동일한 값이 중복 입력되어 필터가 실제보다 안정적인 것처럼 보이는 왜곡이 발생함.

만약 과제 3처럼 100ms 주기로만 읽으면 표본 8개를 모으는 데 0.8초가 소요되어, 물체를 움직여도 표시가 한참 뒤에 따라오는 문제가 발생함.

### 출력 형식
```c
sprintf(buf, "RAW: %4d | FILTERED: %4d | DISTANCE: %d.%dcm\r\n",
        raw, filtered, mm / 10, mm % 10);
```
거리는 필터를 거친 값으로 계산함. 원시 값으로 계산하면 표시가 안정되지 않아 필터를 적용하는 의미가 없음.

## 6. 동작 설명 및 결과 (Results)

### 동작 시나리오
1. 전원 인가 시 ADC와 UART1을 초기화하고 Timer0을 시작함
2. 40ms 주기로 PSD 값을 읽고 이동 평균 필터를 통과시킴
3. 200ms 주기로 원시 값, 필터 값, 거리를 함께 출력함
4. 범위를 벗어난 경우 거리 대신 경고를 표시함

```text
filter: Moving Average (N=8)
sample 40 ms, print 200 ms
RAW:  251 | FILTERED:  256 | DISTANCE: 21.3cm
RAW:  274 | FILTERED:  268 | DISTANCE: 19.8cm
RAW:  900 | FILTERED:  480 | DISTANCE: TOO CLOSE
```

### 필터 적용 전후 비교

동일한 입력 조건에서 필터 적용 여부에 따른 출력 변동을 표준편차로 비교함. 기준 값에 잡음이 섞이고 주기적으로 큰 값이 튀는 조건을 사용함.

| 구분 | 원시 데이터 표준편차 | 필터 적용 후 표준편차 | 감소 비율 |
| :--- | :--- | :--- | :--- |
| 필터 미적용 | 53.3 | 53.3 | 기준 |
| **이동 평균 (N=8)** | **53.4** | **15.1** | **약 3.5배** |

이동 평균 적용 시 변동 폭이 약 3.5배 감소함. 원시 데이터에서 크게 튀는 값이 나타나도 필터 출력은 완만하게 변화하여 거리 표시가 안정됨.

다만 스파이크가 발생한 경우 그 값이 8회 동안 평균에 포함되므로, 필터 출력이 한동안 실제보다 높은 값을 유지하는 구간이 관찰됨. 이는 산술 평균 방식의 구조적 특성이며, 스파이크를 완전히 배제하려면 다른 방식의 필터가 필요함.

### 검증 과정에서 확인한 사항
과제 3에서 확인한 전원 관련 문제(LED 표시로 인한 소비 전류 변동)는 본 과제에서도 동일하게 적용되므로 LED 막대 표시를 비활성화한 상태로 진행함.

필터 표본 수를 늘리면 표시는 더 안정되나 손을 움직였을 때 따라오는 속도가 눈에 띄게 느려짐. 표본 수 8은 안정성과 반응 속도가 모두 확보되는 값으로 판단하여 선택함.
