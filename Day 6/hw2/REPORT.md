## 1. 개요 (Overview)
본 과제는 직접 제작한 L298N 모터 드라이버 기판으로 DC 모터 두 개를 구동하고, 버튼 입력으로 각 모터의 회전 방향을 제어하는 것을 목표로 함. Timer1의 두 비교 채널을 이용한 독립 속도 제어와, H 브리지에서 방향을 뒤집을 때 발생하는 전기적 문제의 처리를 함께 다룸.

### 핵심 목표
* Timer1 Fast PWM 두 채널로 모터 두 개의 속도를 독립 제어
* IN 핀 조합을 통한 회전 방향 제어
* 방향 전환 시 역기전력에 의한 과전류 억제
* 버튼 입력의 모순 상태에 대한 예외처리

## 3. 하드웨어 구성 및 핀 맵 (Hardware Structure)

### Pin Configuration

```text
[ATmega128]                 [L298N]
 PB0                 ----->   IN1 (5번)    ┐
 PB1                 ----->   IN2 (7번)    ├ 모터 A
 PB5 (OC1A)          ----->   ENA (6번)    ┘
 PB2                 ----->   IN3 (10번)   ┐
 PB3                 ----->   IN4 (12번)   ├ 모터 B
 PB6 (OC1B)          ----->   ENB (11번)   ┘

[L298N]                     [Target]
 OUT1 (2번), OUT2 (3번)  ---->   모터 A 양단
 OUT3 (13번), OUT4 (14번) ---->   모터 B 양단
 VS   (4번)            <-----   12V (레귤레이터 스위치 앞에서 분기)
 VSS  (9번)            <-----   5V
 GND  (8번), SENSE_A (1번), SENSE_B (15번)  ---->  GND

[ATmega128]                 [Switch]
 PC0, PC1            <-----   SW1, SW2
 PD2, PD3            <-----   SW3, SW4
```

### 전원 구성

12V는 레귤레이터 기판의 슬라이드 스위치 앞쪽에서 분기하여 VS로 공급함. 스위치 뒤에서 분기하면 모터 전류 전체가 스위치 접점을 통과하게 되는데, 소형 슬라이드 스위치의 정격은 0.3~0.5A인 반면 모터 두 개의 기동 전류는 1~2A를 넘음. 스위치는 7805 입력 전류만 담당하도록 구성함.

| 위치 | 전원 | 용도 |
| :--- | :--- | :--- |
| VS (4번) | 12V | 모터 구동 전원 |
| VSS (9번) | 5V | 로직 전원 |

각 레일에 100uF을 배치함. 회로도에는 두 커패시터가 나란히 그려져 있으나 확대하여 확인한 결과 좌측은 5V, 우측은 12V 노드에 각각 연결됨.

### SENSE 핀

1번과 15번은 이름과 달리 각 브리지 하단 트랜지스터의 이미터이며, 모터 전류가 GND로 빠져나가는 유일한 경로임. 전류 감지용 저항을 달지 않는 경우 GND에 직결해야 함. 이 핀이 부유하면 로직은 정상이지만 모터 전류가 흐를 수 없어 무동작 상태가 됨.

### 플라이백 다이오드

각 출력마다 12V 쪽과 GND 쪽으로 다이오드를 배치하여 총 8개를 구성함. 회로도상 8개 모두 캐소드가 같은 방향(12V 쪽)을 향함.

```text
       12V ─┬─────────┬─────────┬─────────┬──
            ▲         ▲         ▲         ▲     (캐소드가 위)
          OUT1      OUT2      OUT3      OUT4
            ▲         ▲         ▲         ▲
       GND ─┴─────────┴─────────┴─────────┴──
```

## 5. 핵심 코드 및 레지스터 설정 (Key Implementation)

### PWM 설정

5일차 자료의 ICR1 방식을 따라 Fast PWM 모드 14(TOP = ICR1)를 사용함.

```text
TOP = F_CPU / (분주 x 주파수) - 1
    = 16,000,000 / (1 x 5,000) - 1 = 3199
```

```c
TCCR1A = (1 << COM1A1) | (1 << COM1B1) | (1 << WGM11);
TCCR1B = (1 << WGM13) | (1 << WGM12) | (1 << CS10);
ICR1 = PWM_TOP;
```

| 레지스터 | 값 | 의미 |
| :--- | :--- | :--- |
| TCCR1A | 0xA2 | COM1A1, COM1B1 (비반전), WGM11 |
| TCCR1B | 0x19 | WGM13, WGM12, CS10 (분주 1) |
| ICR1 | 0x0C7F | 3199 |

Timer1은 비교 채널 A와 B가 카운터를 공유하므로 주기는 같고 듀티만 각각 줄 수 있음. 보드에서 ENA가 PB5(OC1A), ENB가 PB6(OC1B)에 물려 있어 좌우 모터를 하나의 타이머로 독립 제어할 수 있음.

분주비를 8로 두어도 TOP이 399로 정수가 되지만 카운트 칸이 8분의 1로 줄어 듀티 해상도가 낮아짐. TOP이 16비트 범위 안에 들어오므로 분주 1을 선택함.

### 초기화 순서

```c
PORTB &= ~(IN_MASK | EN_MASK);
DDRB |= (IN_MASK | EN_MASK);
```

PORTB를 먼저 0으로 만든 뒤 DDRB를 출력으로 전환함. 순서가 반대이면 핀이 출력으로 바뀌는 순간 이전 래치 값이 그대로 출력되어 리셋 직후 모터가 한 번 움직일 수 있음. 디스어셈블로 `andi 0x90`이 `ori 0x6F`보다 먼저 수행되는 것을 확인함.

### 방향과 속도의 분리

방향은 IN 두 핀의 조합이, 속도는 EN 핀의 PWM 듀티가 담당하며 서로 독립임.

| ENA | IN1 | IN2 | 동작 |
| :--- | :--- | :--- | :--- |
| 0 | X | X | 공회전 정지 |
| 1 | 1 | 0 | 정방향 |
| 1 | 0 | 1 | 역방향 |
| 1 | 동일 | 동일 | 급제동 |

속도를 -100부터 +100까지의 값 하나로 다루어 부호가 방향을, 크기가 듀티를 나타내게 함. 상위 로직이 단순해지고 이후 라인트레이서의 PID 출력을 그대로 넘길 수 있는 형태임.

```c
void SET_motorA(int16_t pct)
{
    if (pct > 0)
    {
        PORTB |= (1 << IN1);
        PORTB &= ~(1 << IN2);
    }
    ...
    OCR1A = CONVERT_pctToDuty(pct);
}
```

### 방향 전환 시 데드타임

회전 중인 모터는 역기전력을 발생시키고 있으므로, 여기에 반대 극성의 전압을 그대로 인가하면 실효 전압이 거의 두 배가 되어 순간 전류가 크게 상승함.

```c
if (dirA != DIR_STOP && dirA != lastA)
{
    if (lastA != DIR_STOP)
    {
        SET_motorA(0);
        _delay_ms(DEADTIME_MS);
    }

    lastA = dirA;
}
```

`lastA`는 마지막으로 실제 구동한 방향을 기억하며, 버튼에서 손을 뗀 상태(DIR_STOP)로는 갱신하지 않음. 손을 떼는 것만으로는 모터가 즉시 멈추지 않기 때문에, 정방향 버튼을 떼고 곧바로 역방향 버튼을 눌러도 데드타임이 정상적으로 적용됨.

### 버튼 모순 처리

같은 모터의 정방향과 역방향 버튼이 동시에 눌리면 IN 두 핀이 같은 값이 되어 급제동 상태가 됨. 의도하지 않은 동작이므로 정지로 처리함.

```c
uint8_t READ_dir(uint8_t fwd, uint8_t rev)
{
    if (fwd && !rev)
        return DIR_FWD;

    if (rev && !fwd)
        return DIR_REV;

    return DIR_STOP;
}
```

## 6. 동작 설명 및 결과 (Results)

### 동작 시나리오

| 버튼 | 핀 | 동작 | LED |
| :--- | :--- | :--- | :--- |
| SW1 | PC0 | 모터 A 정방향 | LED0 |
| SW2 | PC1 | 모터 A 역방향 | LED1 |
| SW3 | PD2 | 모터 B 정방향 | LED2 |
| SW4 | PD3 | 모터 B 역방향 | LED3 |

누르고 있는 동안만 회전하고 떼면 정지함. A와 B가 독립이므로 SW1과 SW3을 동시에 누르면 두 모터가 함께 정방향으로 회전하며, SW2와 SW3의 조합으로 제자리 회전을 확인할 수 있음.

### 검증 과정에서 확인한 사항

**전류제한에 가려져 있던 고장**

초기 시험 시 버튼을 누르면 전류가 1.0A에서 멈추고 모터는 회전하지 않았으며 방열판도 발열이 없었음. 전원공급장치의 전류제한을 1A로 설정한 상태였고, 회로가 그 이상을 요구하면서 CC 모드로 진입해 전압이 낮아진 상태였음. 전압이 낮아 손실도 작았기 때문에 발열이 없었던 것이며, 정상 동작으로 오인하기 쉬운 상태였음.

제한을 올리자 2.6A가 흐르고 방열판이 급격히 가열됨. L298N의 채널당 연속 정격이 2A이므로 초과 상태였음. 즉시 전원을 차단하고 배선을 점검하였으며, 최종적으로 L298N을 교체하여 정상 동작을 확인함.

이 과정에서 확인한 것은 **전류제한이 고장을 막아 주지만 동시에 고장을 감추기도 한다**는 점임. CC 램프 점등 자체를 이상 신호로 판단해야 함.

**모터 B 무동작**

모터 A는 정역 모두 정상이나 모터 B가 양방향 모두 동작하지 않는 현상이 있었음. 한 방향만 안 되는 경우는 IN3 또는 IN4 중 하나의 문제이지만, 양방향이 모두 안 되는 경우는 두 방향이 공통으로 사용하는 요소(ENB, SENSE_B, 출력 배선, 모터)로 범위가 좁혀짐.

점검 결과 모터 B 커넥터가 핀에 완전히 삽입되지 않은 접촉 불량이었음. 커넥터 접촉 불량은 부분 동작이 아니라 완전 무동작으로 나타나 소자 고장과 구분이 어려움. 이후로는 배선 점검 시 커넥터 체결 상태를 먼저 확인함.

**보드 간 GND**

레귤레이터 기판과 메인 기판 사이의 GND가 연결되지 않아 MCU가 동작하지 않았던 사례가 있었음. 12V 계통과 5V 계통의 GND는 반드시 한 점에서 만나야 하며, 분리되면 IN 핀의 기준 전압이 부유하여 모터가 임의로 동작할 수 있음.
