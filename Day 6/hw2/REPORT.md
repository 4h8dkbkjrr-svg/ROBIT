## 1. 개요 (Overview)
본 과제는 직접 제작한 IR 센서 배열의 아날로그 출력을 다채널 ADC로 읽고, 이동평균 필터와 정규화를 거쳐 UART, LED, LCD 세 경로로 동시에 출력하는 것을 목표로 함. 개체차가 있는 센서들을 공통 척도로 맞추는 방법과, 출력 부하가 실시간 처리를 방해하지 않게 만드는 구조를 함께 다룸.

### 핵심 목표
* 다채널 ADC 순차 변환 및 채널 전환 처리
* 이동평균 필터(MAF)를 통한 노이즈 제거
* 센서별 min/max 기반 정규화로 개체차 보정
* 정규화 값에 따른 LED 점등 및 UART, LCD 동시 출력

## 3. 하드웨어 구성 및 핀 맵 (Hardware Structure)

### Pin Configuration

```text
[ATmega128]                 [Target Component]
 PF2 ~ PF7 (ADC2~7)  <-----   IR 수광부 6개 이미터
 PA0 ~ PA5           ----->   LED 6개 (Active Low)
 PC0, PC1            <-----   SW1, SW2
 PD0 (SCL)           <---->   I2C LCD
 PD1 (SDA)           <---->   I2C LCD
 PD3 (TXD1)          ----->   USB-Serial 어댑터 RX
 AVCC (64번)         <-----   5V
 GND                 <---->   센서부 GND, 어댑터 GND
```

### IR 센서부 회로

발광부는 제어 없이 상시 점등이며, 수광부의 분압 전압을 ADC로 읽음.

```text
[발광부 EL-8L]  5V ── 100Ω ── 긴 다리(A) ▶| 짧은 다리(C) ── GND

[수광부 ST-8L]  5V ── 짧은 다리(C)
                        │  포토트랜지스터
                    긴 다리(E) ──●──── PF2 ~ PF7
                                 │
                               2.2kΩ
                                 │
                                GND
```

발광부 6개가 소비하는 전류는 개당 약 37mA로 총 220mA임. 기존 5V 부하에 이만큼이 추가되므로 레귤레이터의 발열 여유를 함께 확인함.

### 부품 극성

두 부품의 다리 길이와 극성의 관계가 서로 반대임. 교육자료 3일차 슬라이드의 "긴 다리가 (-)극임" 경고는 슬라이드 배치상 수광부에만 해당함.

| 부품 | 긴 다리 | 짧은 다리 | 일반 LED와 비교 |
| :--- | :--- | :--- | :--- |
| 발광부 (투명) | (+) Anode | (-) Cathode → GND | 동일 |
| 수광부 (검정) | (-) Emitter → 2.2kΩ | (+) Collector → 5V | 반대 |

### 센서 배치

데이터시트상 발광부 반각은 17.5도, 수광부 반각은 20도임. 감지 높이 10mm에서 두 소자의 조사 원뿔과 수광 시야가 겹치려면 간격이 다음 값 이내여야 함.

```text
d_max = h x (tan 17.5° + tan 20°) = 10 x (0.3153 + 0.3640) = 6.79mm
```

만능기판 격자(2.54mm)에서 선택 가능한 값은 5.08mm(2홀)와 7.62mm(3홀)인데, 후자는 한계를 12% 초과하므로 세트 내 간격을 5.08mm로 잡음. 세트 간 피치는 라인 폭 18mm에 두 개 이상이 걸리도록 10.16mm(4홀)로 함.

### 핀 할당

```text
PF0 : PSD 2번    (가변저항 제거 후 배정)
PF1 : PSD 1번
PF2 ~ PF7 : IR 센서 6개
```

과제 문구는 IR 센서 8개를 전제하고 있으나, 4일차 과제 안내에서 PF1을 PSD로 재배정하고 IR 센서를 6개로 축소하도록 지시하고 있어 이에 따름. 이로 인해 센서 번호와 ADC 채널이 2만큼 어긋남.

## 5. 핵심 코드 및 레지스터 설정 (Key Implementation)

### JTAG 해제 (task1.c)

PF4부터 PF7까지는 JTAG 인터페이스 핀이며, JTAGEN 퓨즈가 공장 출하 시 활성화되어 있음. 해제하지 않으면 이 네 핀이 ADC 입력으로 동작하지 않음.

```c
MCUCSR |= (1 << JTD);
MCUCSR |= (1 << JTD);
```

재배정으로 IR 센서 6개 중 4개가 이 핀에 배치되었으므로, 누락 시 절반 이상이 동작하지 않음. 4클럭 이내에 두 번 연속으로 써야 적용되므로 두 줄 사이에 다른 코드를 두지 않음. 퓨즈를 직접 변경하는 방법도 있으나 실패 시 복구가 어려워 코드 방식을 선택함.

### 다채널 ADC

```c
uint16_t READ_adc(uint8_t ch)
{
    ADMUX = (1 << REFS0) | (ch & 0x1F);     // 기준전압 AVCC(5V)
    _delay_us(10);                          // 채널 전환 후 입력이 안정될 시간

    ADCSRA |= (1 << ADSC);
    while (ADCSRA & (1 << ADSC));

    return ADC;
}
```

분주비 128로 ADC 클럭을 125kHz로 설정함. 10비트 정확도는 50kHz에서 200kHz 사이에서만 보장됨. 6채널을 순차 변환하는 데 약 700us가 소요되어 10ms 주기 안에 충분히 들어옴.

ADC 핀의 내부 풀업은 반드시 꺼야 함. 풀업이 켜져 있으면 센서 출력 노드에 전류를 밀어 넣어 분압비가 왜곡됨.

```c
DDRF &= ~0xFC;
PORTF &= ~0xFC;
```

### 이동평균 필터

창 안의 합을 유지하면서 나간 값을 빼고 들어온 값을 더하는 재귀형으로 구현함. 매번 여덟 개를 다시 더하는 방식보다 연산량이 적음.

```c
fSum[i] = (uint16_t)(fSum[i] - fBuf[i][fIdx] + v);
fBuf[i][fIdx] = v;
fltVal[i] = (uint16_t)(fSum[i] >> FILT_SHIFT);
```

창 크기를 8로 잡아 2의 거듭제곱이 되게 함. 평균 계산에서 나눗셈 대신 시프트를 쓸 수 있고, 링버퍼 인덱스도 마스크 연산으로 순환시킬 수 있음. 합의 최댓값은 8 × 1023 = 8184이므로 16비트로 충분함.

시작 시 링버퍼를 첫 측정값으로 가득 채움. 이 처리를 생략하면 버퍼에 남아 있는 0이 min으로 기록되어 정규화 값이 계속 1 근처로만 나옴.

### 정규화

```text
norm = (x - min) / (max - min)
```

부동소수점 연산을 피하기 위해 0부터 1000까지의 정수로 다룸. avr-libc의 printf는 `%f`를 쓰려면 별도의 링커 옵션이 필요하며, 지정하지 않으면 경고 없이 잘못된 문자열이 출력됨.

```c
if (maxVal[i] > minVal[i])
{
    normVal[i] = (uint16_t)(((uint32_t)(fltVal[i] - minVal[i]) * NORM_MAX)
                            / (uint32_t)(maxVal[i] - minVal[i]));
}
else
{
    normVal[i] = 0;                 // 아직 편차가 없다. 0 으로 나누는 것을 막는다
}
```

min과 max가 같은 상태는 부팅 직후와 재보정 직후에 반드시 발생하므로 나눗셈 방어가 필요함. min/max는 원본이 아니라 필터를 거친 값으로 갱신함. 원본으로 잡으면 노이즈 한 번에 범위가 벌어져 이후 정규화 값이 눌림.

### UART 출력 구조

한 블록이 헤더와 6채널, 빈 줄까지 약 380바이트임. 9600baud에서 400ms 가까이 소요되므로 블로킹 방식으로 보내면 그동안 ADC 변환과 LED 갱신이 멈춤. 이동평균의 실효 창 길이가 80ms에서 800ms로 늘어나 필터가 무의미해짐.

링버퍼와 UDRE 인터럽트로 분리함.

```c
ISR(USART1_UDRE_vect)
{
    if (txHead == txTail)
    {
        UCSR1B &= ~(1 << UDRIE1);
    }
    else
    {
        UDR1 = txBuf[txTail];
        txTail = (uint8_t)(txTail + 1);
    }
}
```

버퍼 크기를 정확히 256으로 잡아 uint8_t 인덱스가 별도의 마스크 연산 없이 순환하게 함. 인덱스가 1바이트이므로 ISR과 메인 루프가 동시에 접근해도 상위/하위 바이트가 분리되어 읽히는 문제가 발생하지 않음.

출력은 100ms마다 한 줄씩 내보내 8단계로 한 블록을 완성함. 한 줄이 51바이트로 버퍼를 넘지 않아 메인 루프가 대기 상태에 빠지지 않음.

### 타이머 주기

```text
분주 256  ->  1틱 16us
OCR0 = 124  ->  2ms (오차 0)
2ms x 5   = 10ms   측정
2ms x 50  = 100ms  UART 한 줄
2ms x 100 = 200ms  LCD 갱신
```

카운터 세 개를 모두 uint8_t로 둠. 최댓값이 100이라 넘칠 일이 없고, 1바이트라 메인 루프에서 읽을 때 값이 찢어지지 않음.

1. 전원 인가 시 JTAG를 해제하고 ADC, UART, LCD, Timer0을 초기화함

### 검증 과정에서 확인한 사항

**AVCC 미연결**

ADC 값이 나오기는 하나 오차가 크고 시간에 따라 표류하는 현상이 있었음. AVCC 핀이 5V에 연결되어 있지 않은 것이 원인이었음. AVCC는 ADC뿐 아니라 PORTF 전체의 전원 핀이므로 미연결 시 해당 포트가 정상 동작하지 않음.

다만 핀이 완전히 부유한 상태에서는 내부 보호 다이오드 경로로 전압이 어중간하게 끌려 올라가 ADC가 동작하는 것처럼 보임. 이 경우 기준전압 자체가 불안정한 값이 되어 모든 채널의 값이 함께 어긋나고 온도와 부하에 따라 표류함. 완전히 동작하지 않는 것보다 발견이 늦어지는 유형임. 5V 연결 후 정상 동작을 확인함.

**보드 간 GND 누락**

레귤레이터 기판에서 5V만 메인기판으로 연결하고 GND를 연결하지 않아 MCU가 동작하지 않았음. 레귤레이터 기판의 전원 표시 LED는 자체 기판 안에서 회로가 닫히므로 정상적으로 점등되어, 5V가 만들어졌다는 사실만으로는 보드 간 연결을 판단할 수 없었음. 이후로는 MCU의 VCC 핀과 GND 핀 사이 전압을 직접 측정하여 확인함.

**센서 간격 결정**

처음에는 세트 내 간격을 넓게 잡으려 하였으나, 데이터시트에서 확인한 반각이 각각 17.5도와 20도로 예상보다 좁아 감지 높이 10mm에서의 허용 간격이 6.79mm로 계산됨. 만능기판 격자상 7.62mm는 이를 초과하므로 5.08mm로 확정함. 부품이 3mm 패키지라 5.08mm에서도 몸통 사이에 2.08mm가 남아 열수축튜브로 측면 누화를 차단할 수 있었음.
